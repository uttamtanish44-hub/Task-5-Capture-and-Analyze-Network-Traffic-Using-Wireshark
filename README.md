# Wireshark Network Traffic Analysis

## Overview

This project demonstrates the use of Wireshark to capture and analyze live network traffic. Different network protocols were identified and examined to understand how devices communicate across a network.

## Objectives

- Capture live network packets.
- Analyze common network protocols.
- Understand packet structures and communication processes.
- Learn basic network traffic monitoring techniques.

## Tools Used

- Wireshark 4.6.6
- Windows 11
- Wi-Fi Network Interface

## Protocols Examined

### DNS
Used to translate domain names into IP addresses.

### TCP
Provides reliable communication through acknowledgments and error checking.

### TLS
Provides encrypted communication for secure internet connections.

### QUIC
Modern transport protocol that improves speed and security for web applications.

## Steps Performed

1. Installed Wireshark.
2. Selected the active Wi-Fi interface.
3. Started packet capture.
4. Generated network traffic by visiting websites.
5. Applied filters:
   - dns
   - tcp
   - tls
   - quic
6. Analyzed captured packets.
7. Saved the packet capture file.


## Learning Outcomes

After completing this task, I learned:

- How packet capturing works.
- How DNS resolves domain names.
- How TCP manages reliable communication.
- How TLS secures internet traffic.
- How QUIC improves web performance.
- How Wireshark can be used for network troubleshooting and analysis.

## Conclusion

The project successfully demonstrated packet capture and protocol analysis using Wireshark. The exercise improved practical knowledge of networking concepts and network traffic inspection techniques.
